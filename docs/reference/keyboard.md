# Keyboard shortcuts

| Key | Action |
|---|---|
| Esc | Stop placing or measuring, cancel a drag, close menus, popups and dialogs |
| Ctrl/Cmd + Z | Undo |
| Ctrl/Cmd + Shift + Z, or Ctrl + Y | Redo |
| Delete / Backspace | Remove the selected device from the plan, or the selected measurement (undoable) |
| Arrow keys | Nudge the selected device (Shift = bigger steps) |
| Shift while measuring | Don't snap the line straight |
| Enter | Confirm a length or a name |

Shortcuts don't fire while you type in a field. Undo keeps the last 50 changes of the open plan; a whole drag counts as one change.
